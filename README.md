# iroute.dev

Public landing page and documentation renderer for [iRoute](https://github.com/lazineziri/iRoute).

The canonical versioned engineering documentation remains in the source repository beside the code and contracts. This repository carries a reviewed snapshot for `iroute.dev`; do not make protocol or operational promises here without changing the canonical source first.

## Local development

```bash
npm ci
npm run dev
npm test
```

The site is public and contains no customer data, provider credentials, private evaluation payloads, or runtime secrets.
